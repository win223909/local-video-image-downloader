# Support

Please choose the right channel so questions and reports can be handled efficiently.

## Bug

Use the Bug Report template. Include sanitized environment information, reproduction steps, expected behavior, actual behavior, and relevant non-sensitive logs.

## Feature request

Use the Feature Request template. Explain the user problem, proposed behavior, and any platform or privacy implications.

## Installation help

Include the operating system, installation method, Agent version, Python/FFmpeg status, and the visible error message. Do not include personal paths or credentials.

## Platform compatibility

Platform rules and public endpoints change frequently. Report the platform, public URL shape, Agent version, and the user-visible failure. Do not submit cookies, private links, or account information.

## Security issue

Do not publish security vulnerabilities in an Issue. Follow [SECURITY.md](SECURITY.md) and contact the maintainer privately through GitHub.
